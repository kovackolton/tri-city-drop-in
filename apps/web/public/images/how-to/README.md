# How to screenshots

Place reviewed PNG screenshots here using the filenames in [the screenshot checklist](../../../../../docs/how-to-screenshot-checklist.md). No placeholder image files are required: the app shows a labeled panel until a screenshot can load.

The source of guide text, image IDs/captions and alt text is `apps/web/src/app/how-to/how-to-content.ts`. Commit screenshots and deploy normally; Angular copies this directory to `/images/how-to/`.
